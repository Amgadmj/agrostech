## 📌 Executive Summary (for the CTO)

This repository is the **operating system of Agrostech** — a living, version-controlled representation of the entire company, its agents, processes, integrations, and client data. It is designed so that **any person or AI system** can open this repository and fully understand how the company operates — and eventually run parts of it autonomously.

The core idea is a **Hybrid AI + Human model**:
- **Digital Agents** (AI roles) handle strategy, orchestration, planning, content generation, financial analysis, and compliance
- **Human Workers** handle execution in the field, client relationships, sales negotiations, and physical drone operations
- **ClickUp** is the bridge that delivers AI-generated tasks, briefings, and checklists directly to human workers
- **Telegram Bot** (planned) will give every human employee role-scoped access to the company system from their phone

### Why This Matters

| Traditional Company | Agrostech Digital OS |
|---------------------|----------------------|
| Strategy locked in people's heads | Strategy encoded in agent personas |
| SOPs in forgotten docs | SOPs in version-controlled playbooks |
| CRM data siloed | Client DB in structured, query-ready files |
| Tasks assigned in WhatsApp | Tasks auto-generated by AI in ClickUp |
| Onboarding takes weeks | New hire reads agents/ + playbooks/ |
| Knowledge dies when people leave | Knowledge Agent holds company memory |

```
[Marketing Agent]  →  Lead generated
       ↓
[Head of Sales Agent]  →  Creates daily briefing + base proposal in ClickUp
       ↓
[ClickUp / Sales Space]  →  Telegram notification to Sales Rep
       ↓
[👷 Sales Rep]  →  Makes calls, visits farms, negotiates, closes deal
       ↓
[ClickUp CRM]  →  Rep updates: "Contract Signed"
       ↓
[Account Manager]  →  Notified via Telegram, does onboarding call
       ↓
[Chief Pilot Agent]  →  Creates mission briefing task in ClickUp
       ↓
[ClickUp / Ops Space]  →  Telegram notification to Field Pilot
       ↓
[👷 Field Pilot]  →  Executes drone mission, fills post-mission checklist
       ↓
[ClickUp automation]  →  Triggers Data Processing task
       ↓
[👷 Data Processing]  →  Processes images, QA, packages deliverable
       ↓
[Delivery Agent]  →  Handoff to Account Manager
       ↓
[👷 Account Manager]  →  Presents data to client, collects NPS → Upsell loop
```

## 🛠️ Developer Setup

### Prerequisites
- Python 3.10+
- PowerShell 5.1+ (for integration scripts)
- A ClickUp account with API access
- An LLM API key (OpenAI, Google Gemini, or Anthropic Claude)

### Running the Agent Runners

```bash
cd runner/
pip install -r requirements.txt

# Set your LLM API key
export OPENAI_API_KEY="sk-..."   # or GOOGLE_API_KEY / ANTHROPIC_API_KEY

# Run the CEO agent
python ceo_agent.py

# Run the sales agent
python sales_agent.py
```

### Running ClickUp Integration Scripts

```powershell
# Set your ClickUp API key in integrations/keys.txt first, then:

# Build the full ClickUp workspace structure
cd integrations/
.\build_clickup.ps1

# Push client prospects to ClickUp CRM
.\push_clients.ps1
```

### Using Agent Personas Manually

Each file in `agents/` is a **system prompt**. To use any agent:
1. Open the `.md` file for the role you want
2. Copy the entire content
3. Paste as the **System Prompt** in any LLM interface (ChatGPT, Claude, Gemini)
4. Start talking to that agent in its role

## 📐 Governance Principles (v2.0)

1. **Role autonomy** — Each agent decides within its domain without approval for standard actions
2. **Explicit escalation** — Decisions above threshold (R$10k operational / R$30k commercial) escalate to CEO/COO
3. **Weekly simulation** — CEO syncs all agents every Monday (logged in `okrs/`)
4. **Shared memory** — Knowledge Agent is the central repository of all company context
5. **Quarterly OKRs** — Each layer has OKRs in `okrs/`, reviewed by the CEO agent
6. **Humans supported, not replaced** — Field Pilot, Account Manager, Sales Reps receive briefings, proposals, checklists, alerts — auto-generated by AI
7. **Role-scoped access** — Telegram Bot and ClickUp apply permission based on each employee's role
8. **CRM as source of truth** — All human interactions logged in ClickUp feed the AI with data to improve decisions
