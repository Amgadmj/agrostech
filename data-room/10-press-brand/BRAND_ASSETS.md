## Color palette & typography (from `site/index.html`, the live marketing site)

The landing page (`site/index.html`) defines a "night desk" dark theme,
tied to the brand green — reusable as the canonical palette reference:

| Token | Value | Use |
|---|---|---|
| `--bg` | `oklch(0.190 0.018 152)` | Background — "ground seen at night, tinted to the brand green" |
| `--ink` | `oklch(0.945 0.009 120)` | Primary text |
| `--muted` | `oklch(0.680 0.014 150)` | Secondary text |
| `--accent` | `oklch(0.780 0.152 75)` | "The sodium lamp" — the one saturated accent color |
| `--display` font | Bricolage Grotesque | Headings |
| `--body` font | Public Sans | Body text |
| `--data` font | IBM Plex Mono | Data/numeric display |
