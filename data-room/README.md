# AgrosTech — Data Room

Built for early-stage VC conversations. Structure follows the checklist in
`AgrosTech data room` (Mariya Valeva's data-room framework), grouped into
three parts plus the SAFE terms.

**Status legend used throughout:** 🟡 drafted from known facts · 🔴 needs
founder input or legal review · ✅ ready to share as-is.

## How this is organized

```
data-room/
├── 01-company-snapshot/    One-pager, pitch deck, case study, long-term vision
├── 02-team/                Bios, vesting/ESOP, advisor agreements, org design, hiring plan
├── 03-company-documents/   Incorporation, Brazilian company docs, founders' agreement, board consents
├── 04-investment-documents/ Cap table, use of funds, SAFE, prior rounds, investor update template
├── 05-legal/                IP assignment, trademarks, LGPD, NDA, drone/agro compliance, insurance
├── 06-customers/            Contracts, pipeline, testimonials, market research, KPIs
├── 07-financials/           Financial model, hypotheses, unit economics, tax/compliance
├── 08-gtm-revenue/          GTM strategy, pricing model, ICP, sales playbook
├── 09-product/              Demo video brief, roadmap, tech stack, security overview
└── 10-press-brand/          Brand assets, press kit
```
